# Лендинг врача-нутрициолога Светланы Полежаевой

Одностраничный лендинг для персональных онлайн-консультаций по питанию.

## Структура

- `index.html` — разметка страницы
- `styles.css` — стили и адаптивная верстка
- `script.js` — интерактивность (меню, попапы, анимации)
- `assets/img/` — изображения

## Запуск локально

Откройте `index.html` в браузере или запустите локальный сервер:

```bash
python -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

## Форма записи

Кнопки «Записаться на консультацию» открывают всплывающую Яндекс Форму. Перед реальной публикацией проверьте обработку персональных данных и юридические документы сайта.
